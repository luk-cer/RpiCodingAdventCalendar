13Present Door Alarm

Someone keeps peeking into the present cupboard! Two magnetic reed switches and the active buzzer become a proper alarm system — with arming, an alarm siren and an event log.

🧰You need

  • Pico W + breadboard
  • KY-021 Mini reed switch
  • KY-025 Reed module (red board)
  • KY-012 Active buzzer
  • A magnet
  • 10 jumper wires

🔍How a reed switch works

Inside the little glass tube are two thin metal reeds with a gap between them. A magnet nearby magnetises the reeds, they attract each other and snap together — the switch closes. Take the magnet away and they spring apart. Burglar alarms use exactly this: the switch on the door frame, the magnet on the door.

The KY-021 is just the reed switch plus a resistor. The KY-025 adds a comparator (like Day 12's KY-028), giving a clean digital output on DO and an LED that shows the state.

The glass tube is fragile. Don't bend its legs close to the glass.

2. A Door class

Both sensors behave the same way from the program's point of view: open or closed. We hide the details in a class. At start-up the magnet must be in place (doors closed) — just like Day 2, we remember that level as "closed".

Only one magnet? Hold it so that it's near both sensors at start-up, or start with one sensor and remove the other from the list.

⭐Exercise: entry delay and a secret disarm

Real alarms give the owner time to switch them off. Turn the program into a state machine with four states:

  1. ARMED — opening the cupboard starts the entry delay.
  2. ENTRY — 10 seconds of slow chirping. The owner disarms by holding the magnet to the secret drawer sensor for 2 seconds. If time runs out → ALARM.
  3. ALARM — continuous siren pattern for 20 s (non-blocking!), then back to ARMED if all doors are closed.
  4. DISARMED — silent. Holding the magnet to the drawer sensor for 2 s again re-arms (with three chirps).

For this exercise the drawer sensor is a "key", so treat magnet present (not "open") as the interesting state. Log every state change.

Hint

Keep state and state_since = ticks_ms(). For the 2-second hold, remember when the magnet first appeared (key_since) and reset it to None when it disappears. Make the siren non-blocking by deciding the buzzer's on/off from the elapsed time, e.g. (elapsed // 200) % 2.

Show solution

Every pass through the loop asks "what state am I in, and has the condition to leave it happened?". Sound patterns are computed from the time since entering the state, so nothing ever blocks.

key_since = key_since or time.ticks_ms() keeps the old value if there is one, otherwise sets the current time — a compact Python idiom. Careful: it would misbehave if ticks_ms() were exactly 0, which is extremely rare.
