Pico W Coding Advent Calendar · Before you start

0Setup & Safety

Install MicroPython on your Pico W, get the Thonny editor running, and learn the handful of rules that keep your parts alive for all 24 days.

🧰What you need for the whole calendar

In your box

  • Raspberry Pi Pico W (with headers soldered on)
  • AZ-Delivery 35-in-1 sensor kit (the KY-xxx modules)

Extras (cheap, but you'll need them)

  • Micro-USB data cable (some cables are charge-only!)
  • Full-size breadboard (830 holes) and ~20 male-to-male jumper wires
  • At least four 220 Ω resistors (anything 150–330 Ω works)
  • A small magnet (a fridge magnet is fine) — Days 13 & 14
  • Any TV / IR remote control — Day 22
  • A tea-light candle and an adult nearby — Day 17

💾1. Install MicroPython on the Pico W

  1. Download the latest Pico W firmware (.uf2 file) from micropython.org/download/RPI_PICO_W. Make sure it's the W version — the plain Pico firmware has no Wi-Fi.
  2. Hold down the white BOOTSEL button on the Pico and, while holding it, plug the USB cable into your computer. Release the button.
  3. A USB drive called RPI-RP2 appears. Drag the .uf2 file onto it. The drive disappears and the Pico reboots — MicroPython is installed.

  1. Download Thonny from thonny.org (Windows, macOS, Linux).

🗂️3. How code runs on the Pico

  • Shell / REPL: type one line, it runs immediately. Perfect for trying things — this is how the "In [n]" cells on each day work best.
  • Run (F5): runs the file in the editor. Press Stop (red button, or Ctrl+C in the shell) to interrupt.
  • main.py: if you save a file called main.py onto the Pico (File → Save as → Raspberry Pi Pico), it runs automatically at power-up, even without a computer.
  • View → Plotter: if your program prints numbers, Thonny draws them as a live graph. Many days use this for sensor readings.

📍4. The Pico W pins

All diagrams in this calendar place the Pico the same way: USB on the left, pins in rows c and h. Pin labels are printed on the drawing (zoom in!). In code you always use the GP number, e.g. Pin(15) is GP15, which is physical pin 20.

Pin nameWhat it is
GP0 … GP22General-purpose input/output. All can do digital in/out and PWM.
GP26, GP27, GP28Also analog inputs ADC0, ADC1, ADC2 — the only three pins that can measure voltages.
3V3 (pin 36)3.3 V output. This is what we power the sensor modules from.
GNDGround (0 V). There are eight GND pins; they're all the same.
VBUS (pin 40)5 V straight from USB. Only used for the relay on Day 12.

⚠️5. Safety rules (read these!)

  1. The Pico is a 3.3 V device. Never connect 5 V (VBUS/VSYS) to a GPIO pin — it can destroy the chip. Power all modules from the 3V3 pin unless a day says otherwise.
  2. Unplug USB while you change wiring. A misplaced wire for a split second is the most common way to kill a board.
  3. Never connect 3V3 directly to GND. Double-check red and black wires before plugging in.
  4. Follow the labels on your module, not just the picture. The KY modules come in slightly different versions and the pin order (S, +, −) is not always the same. S = signal, + or VCC = 3.3 V, − or G/GND = ground.
  5. LEDs without a built-in resistor need one (220 Ω). The diagrams show where.
  6. The relay module (Day 12) is for low voltages only. Never connect mains electricity to it.
