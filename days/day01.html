Pico W Coding Advent Calendar · Day 1

1Traffic Light

Your first real circuit: make three LEDs behave like a traffic light. Along the way you'll learn what a GPIO pin is, how to switch it on and off, and how to make the Pico wait.

Haven't set up your Pico W yet? Do the setup page first — it takes about 10 minutes and you only need to do it once.

🧰You need

  • Raspberry Pi Pico W + USB cable
  • Breadboard
  • LED Traffic Light module
  • 5 jumper wires

🔌Wiring

The traffic light module already has a resistor for each LED on board, so we can connect it straight to the Pico. Each LED gets its own GPIO pin, and all three share one ground (GND) connection.

Always wire with the USB cable unplugged. And always follow the labels printed on your module — pin order can differ between batches. The diagram shows R Y G GND; if yours says GND R Y G, just shift the wires accordingly.

How a breadboard works: the five holes a–e in one column are connected to each other, and so are f–j. The long rails at the top and bottom are connected along their whole length. That's why a wire in i21 is connected to the Pico pin sitting in h21.

📓Code, step by step

Open Thonny, make sure the bottom-right corner says MicroPython (Raspberry Pi Pico), and type each cell into the Shell (the REPL) or into the editor and press Run (F5). Running cells one by one is the best way to see what each line does.

1. Say hello with the on-board LED

Every program starts by importing what it needs. machine is the MicroPython module that talks to the hardware; Pin represents one GPIO pin. The Pico W's little green LED is wired to the Wi-Fi chip, so instead of a number we use the special name "LED".

Try led.off() and led.toggle() in the shell. toggle() flips the state — on becomes off and off becomes on.

2. Blink!

time.sleep(0.5) pauses the program for half a second. A loop with toggle() and sleep() gives you the "Hello World" of electronics.

3. Control the traffic light

Now the external LEDs. Pin(15, Pin.OUT) means GP15 — the number is the GPIO number printed on the diagram, not the physical pin number (GP15 is physical pin 20). Setting the value to 1 puts 3.3 V on the pin and current flows through the LED to GND; 0 switches it off.

If the wrong colour lights up, you swapped two wires — either move the wires or swap the numbers in the code. Both are fine!

4. A helper function

Writing three .value() lines for every state gets repetitive. A function bundles them up. show(1, 0, 0) now means "red on, yellow off, green off".

5. The full traffic light cycle

A real (European) traffic light goes red → red + yellow → green → yellow → red. We loop forever with while True:. Pressing Stop in Thonny raises a KeyboardInterrupt; we catch it with try/except so we can switch all LEDs off neatly instead of leaving one glowing.

Everything together

Save this as main.py on the Pico (File → Save as → Raspberry Pi Pico) and it will run automatically every time the Pico gets power — even from a phone charger.

🧠What you learned

  • Pin(n, Pin.OUT) turns GPIO n into an output; .value(1)/.value(0), .on(), .off(), .toggle() control it.
  • GPIO numbers (GP15) are different from physical pin numbers (20).
  • time.sleep(seconds) pauses; functions remove repetition; try/except KeyboardInterrupt cleans up when you stop.

⭐Exercise: data-driven traffic light with night mode

  1. Instead of four hard-coded show(...) lines, describe the cycle as a list of tuples (r, y, g, seconds) and loop over it. Adding a new phase should mean adding one line of data, not code.
  2. After 3 full cycles, switch to night mode: the yellow light blinks (0.5 s on, 0.5 s off) 10 times, then normal operation starts again.
  3. Bonus: make the on-board LED blink once at the start of every cycle so you can see the loop counting.
Hint

for r, y, g, secs in PHASES: unpacks each tuple into four variables. Use a counter variable and the modulo operator % (or just an inner for loop) to know when 3 cycles have passed.

Show solution

The whole cycle is now data. The for _ in range(3) loop runs three normal cycles, then the night-mode loop blinks yellow; the outer while True repeats everything forever. _ is the conventional name for a loop variable you don't use.

Notice how easy it is now to build a different country's traffic light: the US sequence (no red + yellow phase) is just the same list without the second line.
