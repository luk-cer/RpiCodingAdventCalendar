Pico W Coding Advent Calendar · Day 5

5Morse Code Elf

Beep beep beeeep! The active buzzer makes a sound as soon as it gets power. Today you'll teach the Pico Morse code using dictionaries and strings — and in the exercise, build a Morse decoder with the button.

🧰You need

  • Pico W + breadboard
  • KY-012 Active buzzer
  • KY-004 Button (for the exercise)
  • 8 jumper wires

🔌Wiring

An active buzzer has a tiny oscillator inside: give it voltage and it beeps at its own fixed pitch. (Tomorrow's passive buzzer needs us to make the tone ourselves.) Tip: the active buzzer usually has a sticker on top and a sealed black bottom.

The KY-012 is rated for 5 V; at 3.3 V it is a bit quieter, which your family may appreciate. On some boards the middle pin isn't connected at all — wiring it to + does no harm.

📓Code, step by step

1. Beep

To the Pico, the active buzzer is just like an LED: an output pin.

2. Morse code as a dictionary

A dictionary maps keys to values — perfect for "letter → dots and dashes". MORSE["S"] gives "...".

3. Timing rules

Morse timing is all based on one unit: a dot is 1 unit, a dash 3 units, the gap inside a letter 1 unit, between letters 3 units and between words 7 units. We play each symbol on the buzzer and the LED.

4. Whole messages

We walk through the text letter by letter. Spaces mean "word gap". .upper() lets you type in lower case; unknown characters are skipped with .get(), which returns None instead of crashing.

input() waits for you to type into Thonny's shell — so this program turns your Pico into a Morse transmitter.

🧠What you learned

  • Dictionaries ({key: value}, d[key], d.get(key)).
  • Looping over strings, .upper(), continue.
  • Building timing from a single constant so the whole program speeds up or slows down together.

⭐Exercise: Morse key decoder

Turn it around: use the button as a Morse key. The Pico should listen to your presses and print the letters you tap.

  1. While the button is held, the buzzer sounds (so you hear yourself).
  2. A press shorter than 2 units is a dot, longer is a dash.
  3. When the button has been released for more than 3 units, the letter is finished: look it up and print it. After 7 units, print a space.
  4. Use UNIT = 0.2 to start with — tapping fast is hard!
Hint

Build a reverse dictionary: DECODE = {code: letter for letter, code in MORSE.items()}. Keep a string current that collects "." and "-". Record ticks_ms() when the button goes down and when it goes up.

Show solution

The loop tracks two moments: when the key went down (to measure the press) and when it went up (to measure the silence). The variable space_done makes sure a word gap is printed only once.

Pairing with a friend? Connect a second Pico running the transmitter program, or simply tap a message for someone to decode by ear!
