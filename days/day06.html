6Jingle Bells

Happy St. Nicholas Day! The passive buzzer can play any note — if you tell it how fast to vibrate. You'll compute musical frequencies with a bit of maths and play a Christmas classic.

🧰You need

  • Pico W + breadboard
  • KY-006 Passive buzzer
  • 3 jumper wires

🔌Wiring

The passive buzzer is a tiny loudspeaker. It only needs signal and ground; the middle pin is not used.

📓Code, step by step

1. A tone is a frequency

Sound is air vibrating. If the buzzer's membrane moves back and forth 440 times per second (440 Hz), you hear the note A. PWM does exactly that: freq(440) makes 440 pulses per second, and a 50 % duty cycle gives the loudest, cleanest square wave.

Try other frequencies between 100 and 4000. Above ~2000 Hz this little buzzer is loudest; low notes are quiet.

2. From note names to frequencies

Every semitone up multiplies the frequency by the 12th root of 2 (≈ 1.0595), so 12 semitones = one octave = double the frequency. Musicians and computers number notes with MIDI numbers: A4 = 69. The formula is f = 440 · 2^((n − 69) / 12).

3. Playing a note

Each note has a pitch and a length in beats. We stop the sound briefly at the end of every note — otherwise two equal notes in a row would melt into one long one.

4. Jingle Bells

A melody is just a list of (note, beats) tuples. Data separate from code again — just like the traffic light phases on Day 1.

try … finally runs the finally block no matter how the try block ends — normally, by an error, or by pressing Stop.

🧠What you learned

  • PWM frequency = pitch; 50 % duty = loudest square wave; duty 0 = silence.
  • The equal-temperament formula and MIDI note numbers.
  • String slicing (name[:-1], name[-1]), list.index(), try/finally.

⭐Exercise: an RTTTL ringtone player

Old mobile phones stored ringtones as RTTTL text. Thousands of melodies exist online in this format. Write play_rtttl(text) that plays strings like this:

  • Three sections separated by : — name, defaults, notes.
  • Defaults: d = default duration (4 = quarter note), o = default octave, b = beats (quarter notes) per minute.
  • Each note: optional duration (1, 2, 4, 8, 16, 32), the note letter (a–g, or p for pause), optional #, optional octave digit, optional . (dotted = 1.5× as long). Some files put the dot before the octave, e.g. 8c.6 — handle both.
  • A whole note lasts 4 × 60 / b seconds; duration 8 lasts one eighth of that.
Hint

Use text.split(":") and split(","). Parse a note by walking through its characters: first collect digits (duration), then the letter, then check for #, . and a digit (octave). Reuse note_freq() by building a name like "C#6".

Show solution

The parser reads each note from left to right with an index i. Because the dot may appear before or after the octave, we simply check for it in both places.

Search the web for "RTTTL Christmas" and paste in more songs. Note: b# or e# don't exist in NAMES — a real-world parser would need to handle such oddities.
