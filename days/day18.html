18Secret Knock

Only elves who know the secret rhythm may enter Santa's workshop! A knock sensor listens to your rhythm, compares it with the secret one, and a touch sensor lets the owner record a new secret.

🧰You need

  • Pico W + breadboard
  • KY-031 Knock sensor
  • KY-036 Touch sensor (red board)
  • LED Traffic Light module
  • 11 jumper wires

🔍Meet today's parts

KY-031 knock sensor

A spring inside a small housing closes a contact when it's jolted — like Day 7's shock sensor, but tuned for knocks. Tap the table next to the breadboard, or tap the module itself.

KY-036 touch sensor

The bent metal wire acts as an antenna: your body picks up electrical "hum" from the mains wiring around you, and touching the wire feeds that into an amplifier. The comparator turns it into a digital signal on DO.

🔌Wiring

📓Code, step by step

1. Test the sensors

Like the shock sensor, a knock is so short you'll rarely catch it by polling — interrupts to the rescue again. For the touch sensor, turn the potentiometer until the board's second LED lights only while you touch the wire. Note which value means "touched":

2. Collect knock times

The handler stores a timestamp per knock. A real knock makes the spring bounce several times, so anything within 100 ms of the previous knock is ignored.

3. Listen for a whole pattern

A pattern starts with the first knock and ends after 1.5 s of silence. We return the intervals between knocks — the rhythm.

4. Compare rhythms, not speeds

Nobody knocks at exactly the same speed twice. So we normalise: divide every interval by the longest one. Fast or slow, "shave and a haircut … two bits" always becomes roughly [0.5, 0.25, 0.25, 0.5, 1.0, 0.5]. Then each interval must be within 25 % of the secret.

5. The workshop door

Red = locked. Knock correctly → green for 5 seconds. Touch the sensor → yellow: knock a new secret to store it.

🧠What you learned

  • Turning timestamps into intervals; normalising data so it can be compared.
  • Pattern matching with a tolerance; all() and zip().
  • How a capacitive/"hum" touch sensor works.

⭐Exercise: a lock that remembers and resists guessing

  1. Persistence: a new secret is lost when the Pico restarts. Save it to a file secret.json and load it at start-up (fall back to the default if the file doesn't exist).
  2. Lockout: after 3 wrong attempts in a row, block the lock for 30 seconds: red blinks slowly and knocks are ignored. A correct knock resets the counter.
  3. Safety: only accept a new secret if it has at least 3 knocks (2 intervals) — otherwise yellow blinks and the old secret stays.
Hint

import json; save with json.dump(SECRET, f) and load with json.load(f). Opening a missing file raises OSError — catch it. During lockout, call knocks.clear() regularly so old knocks don't count afterwards.
