Pico W Coding Advent Calendar · Day 7

7Shake the Snow Globe

Three modules in one go: a tilt switch, a shock (vibration) switch and a self-flashing 7-colour LED. You'll build a "snow globe" that lights up when you shake or tip it — and meet interrupts, the Pico's way of reacting instantly.

🧰You need

  • Pico W + breadboard
  • KY-020 Tilt switch
  • KY-002 Shock / vibration switch
  • KY-034 7-colour flashing LED
  • 9 jumper wires

🔍Meet today's parts

KY-020 tilt switch

A tiny metal ball rolls inside a can. Upright, the ball connects two contacts; tipped over, it rolls away and the connection opens.

KY-002 shock switch

A spring around a metal pin. A knock makes the spring wobble and briefly touch the pin — the pulses last only milliseconds, which is why we need interrupts.

The KY-034 has a little chip inside the LED that cycles through colours on its own. We just switch its power on and off with a GPIO pin.

🔌Wiring

The KY-034's middle pin isn't needed. If it doesn't flash, check which outer pin is marked S — the LED only works one way round.

📓Code, step by step

1. Test each part

Tip the breadboard while it runs: the tilt value changes and stays changed. Now tap the table hard: the shock value probably never changes in the printout! The pulse is so short that it happens between two of our readings. Polling every 100 ms misses it.

2. Interrupts

An interrupt (IRQ) asks the hardware to watch the pin for us. When the voltage changes, MicroPython pauses whatever the program is doing, calls our handler function, then carries on. We'll count every shock this way.

  • global lets the handler change variables defined outside it.
  • We watch both edges, so it works whether your module idles high or low.
  • Handlers should be short and fast: count, remember a time, done. No printing, no sleeping.

3. Which way is up?

Like the button on Day 2, we remember the tilt switch's value at start-up (with the breadboard lying flat) and treat anything different as "tipped".

If your switch reads "tipped" while flat, it may be mounted the other way — just stand the module up or bend it gently so the can points up.

4. The snow globe

Shaking lights the globe for 3 seconds; every new shake extends the time. Tipping it over keeps it lit as long as it's tipped. The main loop only compares times — no long sleeps.

time.ticks_add(t, ms) calculates a future tick value safely; ticks_diff(future, now) > 0 means "the future hasn't arrived yet".

🧠What you learned

  • Polling misses short events; interrupts (pin.irq(...)) catch them.
  • Interrupt handlers must be short; use global to share data with the main loop.
  • ticks_add for deadlines; combining conditions with or.

⭐Exercise: shake to wake

Make the globe harder to wake up — like a magic spell:

  1. The light only switches on after 5 shakes within 2 seconds. Fewer, or slower, shakes do nothing.
  2. Once on, it stays on for 10 seconds, then switches off.
  3. Turning the globe upside down (tilt) switches it off immediately and resets everything.
  4. Print a little progress bar like ***.. as shakes add up.
Hint

Keep a list of timestamps of recent shakes. Each time a new shake arrives, append ticks_ms() and throw away entries older than 2 seconds. If the list has 5 or more entries, wake up.

Show solution

The handler still only counts. The main loop turns new counts into timestamps and keeps a "sliding window" of the last 2 seconds using a list comprehension.

The progress bar prints every loop while shakes are in the window; for a cleaner output, print only when len(recent) changes.
