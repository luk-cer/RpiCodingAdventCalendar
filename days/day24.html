📓Code, step by step

1. Keep your password out of your code

Create a separate file on the Pico called secrets.py. Your main program imports it, so you can share the main program without sharing your password.

2. Connect to Wi-Fi

network.WLAN(network.STA_IF) is the Wi-Fi chip in "station" mode (a normal client, like your phone). We wait up to 15 seconds for the connection; the on-board LED blinks while waiting.

Write down the IP address. Your phone or computer must be on the same Wi-Fi network to reach it.

5. The page

The HTML lives in a Python string. {temp} and {colour} are placeholders we fill with .replace() (not .format(), because the CSS curly braces would confuse it). The colour picker submits a form to /color.

6. Serve!

A socket is one end of a network connection. We bind to port 80, listen, and then loop forever: accept a visitor, read the request, act on it, send the page, close. After an action we send a redirect back to /, so refreshing the browser doesn't repeat the action.

Open the address on your phone. Change the colour, play the song — the Pico W is now on your network! 🎉

⭐Exercise: live dashboard and a twinkling tree

  1. Add a JSON endpoint /api that returns {"temp": 21.5, "colour": "#00ff20"} with Content-Type: application/json.
  2. Add a little JavaScript to the page that fetches /api every 3 seconds and updates the temperature without reloading.
  3. Add a "Twinkle" mode button: the tree slowly cycles through the rainbow — while the server keeps answering requests. (Right now accept() blocks forever, so nothing else can happen!)
  4. Bonus: the temperature reading takes 750 ms. Read it in the background every 5 seconds and serve the last known value instantly.
Hint

server.settimeout(0.05) makes accept() give up after 50 ms with an OSError. Catch it and use that moment to update the animation. In JavaScript: setInterval(async () => { const r = await fetch('/api'); const j = await r.json(); ... }, 3000). Use json.dumps() on the Pico.

Show solution

The server loop is now an event loop: every 50 ms it either handles a visitor or gets a timeout and does background work (animation step, occasional temperature reading). For the background reading we start a conversion and only read it 750 ms later, so we never sit and wait.

About the odd-looking <""" + """/script> near the end of PAGE: Python glues the two strings back together into a normal closing tag. It's only split so that this web page doesn't mistake it for the end of the code cell — you can write it in one piece in your own file.

For bigger projects, MicroPython's asyncio module makes this kind of "many things at once" programming even neater. A great next step after Christmas!
