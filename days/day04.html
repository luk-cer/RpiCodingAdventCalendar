4Rainbow Mixer

Red, green and blue light can make (almost) any colour. Today you'll drive two RGB LEDs, write your first class, and turn colour wheels into code with the HSV colour model.

🧰You need

  • Pico W + breadboard
  • KY-016 RGB LED module
  • KY-009 SMD RGB LED module
  • 3 × 220 Ω resistors
  • 11 jumper wires

🔌Wiring

Both modules are common cathode: three LEDs (R, G, B) share one − pin. The KY-016 has resistors on the board, so it connects directly. The tiny KY-009 has none, so its three colours go through 220 Ω resistors.

Pin order differs between batches (e.g. B G R − or − R G B). Follow your labels. If your KY-016 has no resistors on the back (look for three tiny black rectangles), add resistors to it too.

We have two RGB LEDs, so instead of copying functions we create a class — a blueprint. Each object made from it remembers its own three pins (stored on self). The colour is given the way web designers do: three numbers from 0 to 255.

⭐Exercise: Christmas colour crossfader

  1. Make a list of Christmas colours as hex codes, e.g. red #ff0000, gold #ffaa00, green #00ff20, icy blue #40a0ff, warm white #ffd0a0.
  2. Add a method fade_to(r, g, b, ms) to the class that smoothly crossfades from the current colour to the new one over ms milliseconds. The LED must remember its current colour.
  3. LED 1 cycles through the list forwards, LED 2 backwards. Each colour is held for 1 s, each fade takes 1.5 s.
Hint

Store self.rgb = (r, g, b) inside color(). A crossfade is linear interpolation: for t from 0 to 1, each channel is start + (end - start) * t. To fade two LEDs at the same time, write the fade as a loop in the main program that updates both LEDs each step.

Show solution

Fading both LEDs simultaneously means the loop must interpolate both at once, so fade_to is split into a helper mix() that calculates an in-between colour, and a module-level fade_both() that steps both LEDs together. The class still has a single-LED fade_to() for convenience.
